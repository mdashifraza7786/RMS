Admin Role

Full System Control

13 modules — manage every aspect of the restaurant

Dashboard
Financial overview with period filter (today / 7d / 30d / all), quick stats — tables, active orders, revenue per order, daily average — plus recent payments & recent table orders panels.
Orders History
Paginated list of all orders with status filter. View full invoice — subtotal, GST, discount, payment method, assigned waiter & chef. Download invoice.
Active Orders & Staff Assignment
Live scrollable queue of all active orders. Admin can assign a chef and a waiter to any order directly from the dashboard.
Table Management
Create & delete tables, search by number, filter by availability (all / available / occupied). Assign waiters to specific tables when waiter-zones are enabled.
Menu Management
Add, edit, delete menu items — name, price, food type (veg / non-veg), category. Link ingredients from inventory per item so stock auto-deducts on every order.
Inventory Control
Monitor stock levels with low-limit alerts. Add / update / delete inventory items. View kitchen orders, generate bulk purchase orders, review recent order history.
Inventory & Revenue Forecast
Select an item & forecast window to get demand projections via line chart. Switch to revenue forecast mode for projected income trends.
Staff Members
Multi-step registration — basic info, address, payout setup. View, edit, delete staff across all roles (admin / waiter / chef / washer). Search by name or ID.
Attendance Tracking
Calendar date picker to browse any date. All staff records with timestamps & role badges. Filter by role. Update attendance status for any staff member.
Staff Payouts
View paginated payout list. Generate payouts for staff. Approve or reject pending payouts. View payout details — bank account, IFSC, UPI ID, branch. Filter by status.
Expense Tracking
Log operational expenses — name, amount, frequency, date. Edit or delete entries. Search & filter by frequency tab with paginated listing.
Analytics & Charts
6 interactive Recharts — Sales, Profit/Loss, Demand, Chef Performance, Waiter Performance, Popular Dishes — with date range controls.
Settings & Themes
General tab — business name, address, phone, GST %, waiter-zones toggle. Theme tab — switch between 10+ UI themes (modern-cards, sunset-orange, royal-purple, etc.).
Waiter Role

Order & Table Service

11 capabilities — from taking orders to processing payment

Dashboard Stats
3-card summary showing Active Orders count, Today's Orders count, and Running Subtotal (₹) across all active orders — all live.
Table View (Occupied Only)
Sees only occupied / active tables on the dashboard, not all tables. Clicking an active table opens the full POS Order Screen for that table.
Menu Browse & Search
Full menu displayed with category grouping. Live search by item name. Shows price and food-type indicator (veg / non-veg) per item.
Place New Order
Select items, adjust quantities in cart, view running subtotal + GST + total. Confirm to place a new order — inventory auto-deducted, kitchen order created.
Add Items to Existing Order
For a table with an active order, append more items — sent to kitchen as additional requests, invoice updated automatically without creating a duplicate bill.
Void Item
Cancel an individual item from an active order. Kitchen is automatically notified, inventory stock is restored, invoice total is recalculated instantly.
Assign Chef to Order
From the active orders queue on the dashboard, waiter can assign a chef to any order (admin can do this too).
Checkout & Payment
Complete order modal — apply flat ₹ or % discount, choose payment method: cash, card, or UPI (UPI shows QR code). Marks invoice paid, table released.
Orders History
View full order history with status filter. View invoice details for any completed order — subtotal, GST, discount, payment method, assigned staff.
Own Attendance
Calendar view to check own attendance history — date, time, and status. Restricted to their own records only; cannot see other staff.
Menu (View Only)
Browse the full menu for item reference — names, prices, categories. Read-only; no add / edit / delete access for waiters.
Chef Role

Kitchen Workflow

8 capabilities — focused entirely on the kitchen queue

Kitchen Stats Dashboard
4-card live summary: Orders in Queue, Pending Items count, Preparing Items count, Ready Items count — auto-updating without page refresh.
Active Order Queue
Scrollable live queue of all active orders on the dashboard. Tap any order card to open the kitchen view for that table's items.
View Ordered Items
Order Screen opens directly on the Order tab (not menu). Chef sees every item, its quantity, and its current status for the selected table.
Update Item Status
Change each item's status: Pending → Preparing → Ready with one tap per transition. Waiter sees the change on their screen in real-time.
Void Awareness
When a waiter voids an item, it is instantly marked voided and removed from the chef's queue — no wasted preparation time.
Orders History
Access the Orders page to browse completed order records and invoice details — read-only reference view.
Own Attendance
Calendar view to check own attendance records by date — time and status. Restricted to their own data only.
Menu (View Only)
Browse the full menu for reference — item names, prices, categories. Read-only; no edit access for chefs.
